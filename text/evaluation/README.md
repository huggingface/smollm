# Evaluation

Evaluation recipes for the SmolLM family live in the version-specific folders:

- [SmolLM3](./smollm3/README.md)
- [SmolLM2](./smollm2/README.md)

SmolLM3 base-model code scores in the [blog](https://huggingface.co/blog/smollm3) use HumanEval+ and MBPP+. Those tasks are defined in [`smollm3/tasks.py`](./smollm3/tasks.py) and listed in [`smollm3/smollm3_base.txt`](./smollm3/smollm3_base.txt).
